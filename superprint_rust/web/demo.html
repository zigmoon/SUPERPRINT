Le noyau Rust tourne-t-il dans un navigateur ?

Cette page charge superprint_core.wasm par la même colle que l’application — superprint-core.js, un script classique — puis exécute le noyau sur de vraies données et compare chaque résultat au repli JavaScript, octet pour octet. Elle ne modifie rien : elle mesure.
