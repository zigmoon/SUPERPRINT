# SUPERPRINT

SuperPrint is a browser-based layout and prepress editor with web, local, and npm launcher distributions.

## Repository layout

- `superprint/`: web application and deployable assets
- `sp213-local/`: local Vite distribution
- `superprint-npm/`: npm launcher

## Current release

- Application: `1.7.332`
- npm launcher: `1.0.75`

The local release archive is generated with `_make_zip.mjs` and is not committed.
