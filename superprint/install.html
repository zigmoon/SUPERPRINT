Privacy policy

SuperPrint does not require an account and does not collect any personal data.

Processing is 100% local

All the work happens in your browser: your documents, images and layouts never leave your machine for rendering.

API keys

The API keys you optionally provide for the AI features are stored only in your browser (local storage) and are sent only to the provider you explicitly choose. They are never sent to SuperPrint servers.

No tracking, no session recording

No analytics, no advertising trackers, no profiling. No session-replay tool (Clarity, Hotjar, Smartlook, LogRocket, rrweb or equivalent) is installed: nothing you type, scroll or click is recorded or replayed.

Fonts — no third party

All typefaces are self-hosted and served from this domain. No request is sent to any font CDN.

Version check (the only third-party request)

Some pages ask the GitHub API for the number of the latest published release, so that a visitor who is on an older version is told there is a newer one. That call discloses the visitor's IP address to GitHub (GitHub, Inc. / Microsoft), as any HTTP request does. No cookie, no identifier and no browsing history are sent or stored. It is the only request this site makes to a third party: there is no analytics, no font CDN, no session recording, no advertising. Blocking it (any content blocker does) only removes the version notice; the software is unaffected.
