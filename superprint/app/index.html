Guide utilisateur & FAQ
Comment exporter mon PDF ?
Utilisez le bouton Exporter PDF dans la barre latérale. Choisissez la qualité, le format, et cliquez sur Exporter. Les repères, fonds perdus et imposition sont gérés automatiquement.
Comment déplacer les pages dans le chemin de fer ?
Ouvrez le Chemin de fer via le bouton dans la barre latérale. Glissez-déposez les miniatures pour réorganiser, ou déposez dans la zone "fin" pour mettre une page en dernière position.
Comment mettre du texte en gras, italique, surligné ?
Sélectionnez le texte dans un bloc, puis cliquez sur B, I, U ou le bouton surlignage. Le style s'applique à la sélection ou à tout le bloc si rien n'est sélectionné.
Comment réinitialiser la typo d'un bloc ?
Cliquez sur le bouton Reset (noir) dans la section typo pour remettre le style par défaut (police, couleur, etc.).
Comment utiliser les guides et repères ?
Activez/désactivez les repères avec le bouton dans la barre latérale. Les traits verts (coupes), rouges (marges) et bleus (sélection) s'affichent selon le mode page ou double page.
Puis-je importer mes propres images ?
Oui, utilisez le bouton "Image" dans la barre d'outils ou glissez-déposez vos fichiers image directement sur la zone de travail. Vous pouvez aussi copier-coller des images depuis le presse-papier.
Comment sauvegarder mon travail ?
SuperPrint fonctionne localement dans votre navigateur. Utilisez le bouton SAVE pour télécharger un fichier .json de votre projet. Vous pourrez le réimporter plus tard pour continuer l'édition.

SUPER PRINT

SuperPrint est un outil de mise en page pensé pour la simplicité et la précision. Il vous permet de composer, recadrer et d'imprimer vos maquettes en quelques clics, sans installation complexe.

L'interface épurée et le guide intégré vous accompagnent à chaque étape pour une expérience optimale.

En résumé

  • Importez une image
  • Recadrez avec l'outil crop
  • Déplacez/redimensionnez la sélection
  • Imprimez en un clic
  • Consultez ce guide à tout moment

Comment utiliser SuperPrint

  1. Cliquez sur Importer pour charger votre image.
  2. Utilisez le crop pour sélectionner la zone à imprimer. Vous pouvez déplacer et redimensionner le rectangle de sélection.
  3. Cliquez sur Imprimer pour lancer l'impression de la zone sélectionnée.

Fonctionnalités principales

  • Déplacement et redimensionnement du crop
  • Impression directe depuis l'interface
  • Guide d'utilisation intégré

Fonctionnalités avancées

Scripts & Automatisation

SuperPrint intègre une API JavaScript complète pour automatiser la création, la mise en page et l'export de vos documents. Utilisez des scripts pour générer des grilles, des lots de textes, ou appliquer des thèmes personnalisés.

  • Génération automatique de blocs et pages
  • Layout dynamique
  • Export batch personnalisé

Accédez à la console de scripts via F12 ou le menu développeur.

Double page & Export PDF HD

SuperPrint gère les mises en page en mode double page pour vos catalogues, livres ou magazines. L'export PDF est disponible en haute définition (72, 150, 300 DPI) pour une qualité professionnelle, avec gestion des fonds perdus et marges de sécurité.

  • Mode double page pour la création éditoriale
  • Export PDF HD (jusqu'à 300 DPI)
  • Fonds perdus et marges configurables

Testez vos exports en 150 DPI avant la version finale en 300 DPI pour optimiser la qualité et le poids du fichier.
