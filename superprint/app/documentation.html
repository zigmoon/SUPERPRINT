SuperPrint est une application SPA entièrement en navigateur, comparable aux suites de PAO professionnelles desktop, permettant de créer des documents multi-pages avec typographie professionnelle, chaînage de texte, outil plume Bézier, masquage d'images, export PDF avec fond perdu et repères d'impression.
SuperPrint is a fully browser-based SPA, comparable to professional desktop DTP suites, enabling multi-page document creation with professional typography, text chaining, Bézier pen tool, image masking, PDF export with bleed and trim marks.

Principe

How it works

SuperPrint peut déléguer le rendu des pages à la carte graphique (GPU) de l'ordinateur pour accélérer sensiblement l'affichage — en particulier sur des documents multi-pages avec de nombreuses images et formes complexes.

SuperPrint can delegate page rendering to the computer's GPU to significantly accelerate display — especially on multi-page documents with many images and complex shapes.

Détection automatique de la carte graphique

Automatic graphics card detection

À l'ouverture du panneau Réglages ⚙ (ou lors de l'écran de bienvenue au premier lancement), SuperPrint interroge WebGL via l'extension WEBGL_debug_renderer_info et affiche le nom exact du GPU détecté — par exemple NVIDIA GeForce RTX 4090, Apple M3 GPU ou Intel Iris Xe Graphics. Si le GPU n'est pas accessible (WebGL désactivé ou non disponible), un message ✗ s'affiche et l'option reste sans effet.

When opening the Settings panel ⚙ (or during the first-launch welcome wizard), SuperPrint queries WebGL via the WEBGL_debug_renderer_info extension and displays the exact detected GPU name — e.g. NVIDIA GeForce RTX 4090, Apple M3 GPU or Intel Iris Xe Graphics. If the GPU is not accessible (WebGL disabled or unavailable) a ✗ message appears and the option has no effect.

La détection n'est effectuée qu'au moment de l'ouverture du panneau Réglages ou de l'écran de bienvenue, pas en continu.

Ce que l'accélération GPU fait concrètement

What GPU acceleration actually does

  • Promotion en couche composite GPU — les conteneurs canvas Fabric.js (.canvas-container, .lower-canvas, .upper-canvas, #canvasScrollArea, .canvas-wrapper) reçoivent will-change: transform + transform: translateZ(0) + backface-visibility: hidden : le navigateur les délègue au compositeur de la carte graphique, libérant le fil principal CPU.
  • GPU compositor layer promotion — Fabric.js canvas containers (.canvas-container, .lower-canvas, .upper-canvas, #canvasScrollArea, .canvas-wrapper) receive will-change: transform + transform: translateZ(0) + backface-visibility: hidden: the browser delegates them to the GPU compositor, freeing the main CPU thread.
  • Cache objet Fabric.js — objectCaching = true activé sur formes (Rect, Circle, Ellipse), images (Image), chemins (Path) et groupes (Group) : chaque objet est bitmapé en mémoire et n'est repaint sur le GPU que s'il est modifié. Le texte (Text, Textbox) conserve toujours objectCaching = false pour un rendu typographique net à tous les niveaux de zoom.
  • Fabric.js object cache — objectCaching = true enabled on shapes (Rect, Circle, Ellipse), images (Image), paths (Path) and groups (Group): each object is bitmapped in memory and only repainted to the GPU when modified. Text (Text, Textbox) always keeps objectCaching = false for sharp typographic rendering at all zoom levels.
  • Re-rendu immédiat — requestRenderAll() est appelé sur tous les canvas actifs lors du basculement.
  • Immediate re-render — requestRenderAll() is called on all active canvases when toggling.
Les gains sont les plus visibles sur les documents comportant beaucoup d'images, de formes complexes ou lors du scroll entre les pages.
Gains are most visible on documents with many images, complex shapes, or when scrolling between pages.

Retravailler une zone ciblée (sélection)

Refine a targeted area (selection)

Une fois une maquette générée, vous pouvez demander à l'IA de retravailler uniquement certains éléments plutôt que de tout régénérer :

Once a layout is generated, you can ask the AI to refine only specific elements instead of regenerating everything:

  • Dans l'aperçu (colonne de gauche), cliquez sur un élément (titre, image, bloc de texte…) ou glissez pour en sélectionner plusieurs (encadré vert).
  • In the preview (left column), click an element (title, image, text block…) or drag to select several (green frame).
  • Un bandeau vert apparaît : « N élément(s) sélectionné(s) — le prochain prompt ne retravaillera que ceux-ci ».
  • A green banner appears: "N element(s) selected — the next prompt will only refine these."
  • Tapez ensuite votre demande (ex. « agrandis le titre », « passe ce bloc en bleu ») : l'IA modifie uniquement les éléments sélectionnés et conserve tout le reste du document strictement identique.
  • Then type your request (e.g. "enlarge the title", "make this block blue"): the AI modifies only the selected elements and keeps the rest of the document strictly unchanged.
  • Pour désélectionner : cliquez sur Effacer dans le bandeau, ou cliquez sur un fond vide de la page. Si rien n'est sélectionné, le prochain prompt régénère une maquette complète (comportement par défaut).
  • To deselect: click Clear in the banner, or click on an empty area of the page. If nothing is selected, the next prompt regenerates a full layout (default behavior).
