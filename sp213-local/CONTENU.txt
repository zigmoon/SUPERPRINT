SUPERPRINT 1.7.553 - CONTENU DU PAQUET
======================================

Ce paquet n'est PAS un site web : c'est le paquet de l'APPLICATION LOCALE,
celui que telecharge l'installeur « npx superprint ».

OU EST QUOI
-----------
index.html ........................ LE LANCEUR (c'est la page du site
                                    install.html, adaptee au paquet).
                                    Ouvrir le serveur local affiche cette page.
package.json, package-lock.json ... dependances du paquet (npm install).
vite.config.js .................... configuration du serveur local.
scripts/ .......................... aide au demarrage (npm run dev).
src/ .............................. ancien moteur du studio local, debranche
                                    depuis la 1.7.480 (le studio de l'app le
                                    remplace) - conserve pour l'historique.public/ ........................... racine servie par le serveur local :
  public/superprint/app/index.html ....... L'APPLICATION SuperPrint (PAO)
  public/superprint/sp213-studio.html .... LE STUDIO IA. Il tourne EN LOCAL :
                                           les modeles travaillent sur votre
                                           machine (WebLLM, sans cle, sans
                                           reseau une fois le modele en cache),
                                           ou avec une cle Groq si vous
                                           preferez le cloud.
  public/superprint/supertypo/index.html . SUPERTYPO (editeur de police)
  public/superprint/documentation.html ... documentation
  public/superprint/api.html ............. API
  public/superprint/install.html ......... page du site (source du lanceur)
  public/superprint/version.txt .......... version du paquet : 1.7.553
  public/js/fabric.min.js ................ moteur canvas (fabric)
  public/js/mammoth.min.js ............... import de documents Word

ADRESSES UNE FOIS LE SERVEUR LOCAL LANCE
----------------------------------------
  http://localhost:5173/ ............................... le lanceur
  http://localhost:5173/superprint/app/index.html ...... l'application
  http://localhost:5173/superprint/sp213-studio.html ... le studio IA (local)
  http://localhost:5173/superprint/supertypo/index.html  SuperTyPo
  http://localhost:5173/superprint/documentation.html .. documentation
  http://localhost:5173/superprint/api.html ............ API

POURQUOI public/ ?
------------------
L'installeur a besoin de package.json A LA RACINE du paquet, et Vite sert le
dossier public/ comme racine du site : l'application vit donc sous
public/superprint/. Rien ne manque, la liste ci-dessus est complete.

INSTALLATION
------------
    npx superprint

Telecharge le paquet, installe les dependances et lance le serveur local.
