Tout ce que vous voulez savoir sur SuperPrint

Everything you want to know about SuperPrint

SuperPrint est-il vraiment sans abonnement ? Does SuperPrint really require no subscription?

Oui, SuperPrint fonctionne sans abonnement, sans compte requis, sans publicité. Vous ouvrez votre navigateur et vous travaillez immédiatement. Zigmoon développe SuperPrint en open-spirit dans le but de démocratiser la création professionnelle.

Yes, SuperPrint works with no subscription, no account required, no ads. You open your browser and start creating immediately. Zigmoon develops SuperPrint with an open spirit to democratize professional creation.

SuperPrint est-il un bon logiciel de PAO professionnel ? Is SuperPrint a good professional DTP tool?

SuperPrint propose les fonctionnalités essentielles d'un logiciel de PAO pro directement dans le navigateur : mise en page multi-pages, typographie professionnelle avec césure automatique, export PDF CMYK, import IDML, calques, gabarits, opérations booléennes. Une solution solide pour les créations professionnelles sans abonnement mensuel.

SuperPrint provides the essential features of a professional DTP tool directly in the browser: multi-page layout, professional typography with automatic hyphenation, CMYK PDF export, IDML import, layers, master pages, boolean operations. A solid solution for professional creations without any monthly subscription.

Faut-il installer SuperPrint ? Does SuperPrint need to be installed?

Non. SuperPrint fonctionne entièrement dans le navigateur web (Chrome, Firefox, Safari, Edge). Aucune installation, aucun téléchargement, aucun plugin. Il peut également être installé comme application PWA sur votre bureau depuis Chrome ou Edge en cliquant sur l'icône d'installation dans la barre d'adresse.

No. SuperPrint runs entirely in the web browser (Chrome, Firefox, Safari, Edge). No installation, no download, no plugin. It can also be installed as a PWA desktop app from Chrome or Edge by clicking the install icon in the address bar.

SuperPrint peut-il exporter en PDF CMYK pour l'imprimerie ? Can SuperPrint export PDF CMYK for commercial printing?

Oui. SuperPrint dispose d'un convertisseur RGB→CMYK intégré et exporte des fichiers PDF adaptés à l'impression professionnelle offset. Il prend en charge les couleurs CMYK, les tons directs Pantone et la simulation d'épreuve écran. L'outil SUPER PRINT CONVERT vous accompagne dans ce workflow.

Yes. SuperPrint has an integrated RGB→CMYK converter and exports PDFs suitable for professional offset printing. It supports CMYK colors, Pantone spot colors and screen proof simulation. The SUPER PRINT CONVERT tool guides you through this workflow.

SuperPrint peut-il ouvrir des fichiers IDML ? Can SuperPrint open IDML files?

SuperPrint peut importer et exporter le format IDML, un format d'échange PAO standard utilisé par les principales suites de mise en page professionnelles. Cela permet d'importer des maquettes existantes et d'exporter des documents SuperPrint vers ces workflows, garantissant l'interopérabilité dans les environnements d'agences.

SuperPrint can import IDML, a standard DTP interchange format used by the main professional layout suites. This allows importing existing layouts and exporting SuperPrint documents into those workflows, ensuring interoperability in agency environments.

Mes fichiers sont-ils sécurisés et privés ? Are my files secure and private?

Oui. Toutes vos données restent 100% locales sur votre appareil. SuperPrint utilise IndexedDB (base de données du navigateur) pour la sauvegarde automatique. Aucun fichier n'est jamais envoyé sur un serveur. Aucun compte n'est requis. La sauvegarde automatique se déclenche toutes les 12 secondes.

Yes. All your data stays 100% local on your device. SuperPrint uses IndexedDB (browser database) for auto-save. No files are ever sent to any server. No account required. Auto-save triggers every 12 seconds.

SuperPrint fonctionne-t-il hors-ligne ? Does SuperPrint work offline?

Oui. SuperPrint est une Progressive Web App (PWA) avec Service Worker. Une fois chargé au moins une fois, il fonctionne entièrement hors-ligne. Parfait pour travailler dans le train, en avion ou sur des connexions limitées.

Yes. SuperPrint is a Progressive Web App (PWA) with a Service Worker. Once loaded at least once, it works entirely offline. Perfect for working on trains, planes or on limited connections.

SuperPrint vs les outils de design web généralistes — quelle est la différence ? SuperPrint vs generalist web design tools — what's the difference?

Contrairement aux outils de design web généralistes, SuperPrint est orienté publication professionnelle (PAO) : véritable gestion des couleurs CMYK, gabarits, calques, chaînage de blocs texte, import IDML, moteur typographique professionnel avec césure. SuperPrint est destiné aux designers, graphistes et professionnels de l'impression. Les outils grand public ciblent la création rapide avec des templates prédéfinis. SuperPrint donne le contrôle total sur votre mise en page.

Unlike generalist web design tools, SuperPrint is focused on professional publishing (DTP): real CMYK color management, master pages, layers, text frame chaining, IDML import, professional typographic engine with hyphenation. SuperPrint is made for designers, graphic artists and printing professionals. General-audience tools aim at quick creation with predefined templates. SuperPrint gives you total control over your layout.

Qu'est-ce que l'accélération GPU dans SuperPrint ? What is GPU acceleration in SuperPrint?

Disponible depuis la version 0.0.4, l'accélération GPU détecte automatiquement votre carte graphique via WebGL (WEBGL_debug_renderer_info) et active la promotion de couche CSS (will-change: transform, translateZ(0)) sur tous les canvas Fabric.js. Cela délègue le rendu au compositeur GPU et active le cache objet intelligent par type. Le rendu est sensiblement plus fluide sur les documents avec de nombreuses images ou formes complexes.

Available since version 0.0.4, GPU acceleration automatically detects your graphics card via WebGL (WEBGL_debug_renderer_info) and enables CSS layer promotion (will-change: transform, translateZ(0)) on all Fabric.js canvases. This delegates rendering to the GPU compositor and enables smart per-type object caching. Rendering is noticeably smoother on documents with many images or complex shapes.

Sur quels systèmes d'exploitation SuperPrint fonctionne-t-il ? What operating systems does SuperPrint support?

SuperPrint fonctionne sur tout système disposant d'un navigateur moderne : Windows 10/11, macOS, Linux, Chrome OS (Chromebook), iPad (Safari/Chrome). Il n'y a aucune dépendance au système d'exploitation.

SuperPrint works on any system with a modern browser: Windows 10/11, macOS, Linux, Chrome OS (Chromebook), iPad (Safari/Chrome). There is no dependency on the operating system.
